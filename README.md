# 🌿 مدونة ومكتبة فضيلة الشيخ أحمد مرتضى حامد الرسمية

منصة إسلامية إيمانية متكاملة ومكتبة مرئية شاملة لفضيلة الشيخ **أحمد مرتضى حامد** (ساحة الأقصر - جمهورية مصر العربية).

---

## 🌟 مميزات المشروع

- **مكتبة مرئية ذكية شاملة**: عرض لجميع الدروس والمحاضرات ومجالس السيرة النبوية مع نظام تصنيف وفلترة وبحث فوري.
- **مشغل فيديو مخصص وسريع**: تشغيل الفيديوهات بجودة عالية عبر نافذة مدمجة فائقة السرعة مع الوضع الخصوصي (`youtube-nocookie`).
- **لوحة تحكم مشرفة متكاملة (`/admin.html`)**:
  - إضافة، تعديل، وحذف الدروس يدوياً وتلقائياً.
  - المزامنة الفورية مع قناة يوتيوب الرسمية لجلب أحدث الدروس بنقرة واحدة.
  - تعديل بيانات الهيرو (العنوان، الوصف، ورفع صور جديدة).
  - إدارة مواعيد دروس الساحة والمجالس الدورية.
  - إدارة وحفظ درر ومواعظ الشيخ.
  - إدارة حساب المشرف وتغيير كلمة المرور المشفرة بأعلى معايير الحماية.
- **مسبحة إلكترونية إيمانية ذكية**: جلسات أذكار تفاعلية مع عداد رقمي، ومؤثرات صوتية، واهتزاز تفاعلي، ومؤقت زمني.
- **تصميم إسلامي ملكي فاخر**: متوافق تماماً مع جميع الأجهزة (شاشات الكمبيوتر، اللابتوب، التابلت، والهواتف الذكية) مع دعم كامل للوضع الليلي والنهاري.
- **بنية برمجية فائقة السرعة (`Zero-Dependency`)**: خادم Node.js محصن بالكامل يعمل بدون أي مكتبات خارجية معقدة.
- **مخبأ محلي متطور للصور (`/api/thumb/:id`)**: لتسريع فتح وتصفح الفيديوهات وتجنب أي حظر من المتصفحات.

---

## 🚀 التشغيل السريع محلياً

```bash
# تشغيل الخادم
node server.js
```

افتح المتصفح على:
- الواجهة الرئيسية: `http://localhost:3000`
- لوحة التحكم: `http://localhost:3000/admin.html`

---

## 🔒 الأمان والحماية

- حماية ضد هجمات القوة الغاشمة (Rate Limiting).
- تشفير كلمات المرور باستخدام خوارزمية `PBKDF2-HMAC-SHA512` مع Salt فريد.
- رؤوس أمان قياسية: `CSP`, `X-Content-Type-Options`, `X-Frame-Options`, `HSTS`.
